# Data review, October 2026 (archived in round 9, 2026-11-17)

This folder is the October 2026 data-review campaign: the worker contracts, every SQL statement
run against CRSP and the download manifest, the check scripts, and the findings they produced. It
answered one question - whether the stage-2 data were fit for the paper, and where the universe,
sector and delisting fields come from - before the replication campaign existed.

It predates `report/replication/` and is kept as the record of that answer, not as a live
reference: the current data decisions are `report/replication/METHOD.md`'s source rows and
`GAPS.md`'s data sections. Its contents are not curated or re-checked. The summary that cites it is
`report/DATA_REVIEW.md`; pages and code comments written before the move still give the old path.
