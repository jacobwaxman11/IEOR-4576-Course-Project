## Setup and reproduction

Use Python 3.10 or later. From the repository root:

```sh
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
make all
```

Re-run `pip install -e ".[dev]"` after pulling a change to `pyproject.toml`: Table 4's Ibbotson
block reads the Goyal-Welch `.xls` through `xlrd`, and without it the check prints a warning and
leaves those 24 cells unscored. `git lfs pull` fetches the factor files under `data/raw/french`
and `data/raw/goyal_welch`; without them the factor-regression rows are not computed either.

The replication pipeline is implemented. Its default `--specification paper` uses
formation-spread standard deviation, stock-value short weights, and separate book
compounding. The explicitly named `legacy` profile preserves superseded settings
for sensitivity analysis. See [the replication summary](report/replication/REPLICATION_SUMMARY.md)
and [the corrections audit](report/replication/ACCOUNTING_CORRECTIONS.md) for measured
results, limitations, and exact reproduction commands. This is a partial replication.
The extension script remains a placeholder; `make all` rebuilds the replication only.

### WRDS access

Data are pulled with the official `wrds` Python package. Each teammate stores
their own credentials once, outside the repository:

```sh
.venv/bin/python scripts/wrds_setup.py   # run in your own terminal; approve the Duo push
```

The script prompts for the password without echoing it and writes it to
`~/.pgpass` (mode 600). Code connects with `project.data.wrds_connection()`,
which reads that file and never takes a password argument. Each new connection
can trigger a Duo push, so reuse one connection per session. API pulls land in
the git-ignored `data/raw/wrds_api/`. Run `pre-commit install` once to block
commits that contain secrets.

The script order is:

1. `scripts/01_get_data.py` — acquire source data.
2. `scripts/02_build_dataset.py` — clean and merge the analysis dataset.
3. `scripts/03_replicate.py` — reproduce the original-paper experiment.
4. `scripts/04_extend.py` — run the extension experiments.

All research logic belongs in the importable `src/project/` package. Notebooks
are for exploration; reported results must be generated by the pipeline.
The `tests/` directory includes cash-flow, timing, data-integrity, and historical
rebuild checks. A good match to published numbers is evidence, not a test target
used to tune the strategy. Generated output stays in ignored `results/`.

## Replication status

**Thesis.** Gatev, Goetzmann and Rouwenhorst (2006) find that a simple pairs-trading rule earns
large, significant excess returns that transaction costs, conventional risk factors and
short-term reversal do not explain. They link the profits to a latent common factor that weakened
after 1988. Rebuilt from CRSP with the paper's stated rules, **the paper's conclusions replicate
but its tables only partly do**. 23 of its 25 claims hold (6 with the paper's numbers, 17 in
substance, plus half of one), and 2 do not hold as stated. 267.5 of the 481 printed cells match
(✓ within 10%, ~ within 25%). The gaps trace to data and to underspecified methods, above all a
reversal factor the paper's description does not pin down.

- **Start here:** [`report/replication/REPLICATION_SUMMARY.md`](report/replication/REPLICATION_SUMMARY.md),
  which has the thesis, every table and figure against the paper, and the claims checklist.
- **Generated tables and Figures 1-4:** [`report/replication/outputs/`](report/replication/outputs/);
  cell by cell: [`REPLICATION_CHECK.md`](report/replication/REPLICATION_CHECK.md).
- **Score history and counting rule:** [`report/replication/SCORE_LOG.md`](report/replication/SCORE_LOG.md).

- **Systematic risk (Tables 4 and 8).** With French's short-term reversal factor (ST_Rev), the
  paper's conclusion replicates: pairs returns load little on the Fama-French, momentum and
  reversal factors, and keep a significant Newey-West alpha before 1989 and after 1988, smaller
  in the second period. Cell-level agreement is poor (Table 8: 19.5 of 72), because the paper's
  own reversal factor is unidentified before 1989 and most post-1988 coefficients are
  statistically zero, with our post-1988 all-pairs portfolio off by an era split in the stock
  universe. Details: [`REVIEW_NOTES.md`](report/replication/REVIEW_NOTES.md) sections 50-52.
- **Every claim, with evidence.** [`CLAIMS.md`](report/replication/CLAIMS.md) lists each
  substantive claim of the abstract, sections 3.1-3.9 and the conclusion, the cells behind
  it and a verdict, including the Table 7 long/short result.
- **The paper's own consistency.** What the printed statistics imply about the unnamed reversal
  factor is set out in [`PAPER_CONSISTENCY.md`](report/replication/PAPER_CONSISTENCY.md).
- **Open gaps** are tracked in [`OPEN_QUESTIONS.md`](report/replication/OPEN_QUESTIONS.md).

All 26 acquired raw download files are represented in Git LFS: 16 French archives,
seven CRSP exports, and three Goyal–Welch source files. After cloning, install
Git LFS and run `git lfs pull` to retrieve the files (approximately 4.67 GB total).
The 4.42 GB daily-stock archive is stored as three lossless parts to fit GitHub's
per-file limits; concatenate them using [the reassembly instructions](data/raw/crsp/README.md).
See [data/README.md](data/README.md) for the download inventory, source attribution,
checksums, and reacquisition details.

The blanket `data/` ignore from the course template is omitted. Hosting these
files does not grant additional rights to third-party data; vendor licensing
and source attribution still apply. Intermediate/processed CRSP and TAQ data
remain ignored.
See the [WRDS data policy](https://wrds-www.wharton.upenn.edu/pages/about/data-download-and-analysis-policy/).
Generated results are ignored, apart from directory placeholders, and should be
rebuildable once the pipeline is implemented. Never commit credentials.

## Existing WRDS web exports

The importer preserves the original source and writes a SHA-256 audit manifest.
It rejects conflicting security-day records; exact duplicate analysis rows are
collapsed. CIZ `dlyret` already contains delisting returns.

```sh
python scripts/import_wrds_ui.py --daily-csv /path/to/daily_stocks.csv.gz --index-csv /path/to/daily_indexes.csv.gz
python scripts/03_replicate.py --specification paper
```

Do not mix old cohort caches with the corrected baseline: cache format 6 and all
method settings are checked. Use a new `--cache-root` or explicitly rebuild with
`--force`. Claim experiments reject incompatible input and output caches too.
