# IEOR-4576-Course-Project
IEOR 4576: DATA-DRIVEN METHODS IN FINANCE – Course Project

Extending Pairs Trading: Performance of a Relative-Value Arbitrage Rule - Gatev, E., Goetzmann, W. N., & Rouwenhorst, K. G. (2006)

## Team

Jared Cohen, Jacob Waxman, Eiko Reisz, and Hao Wang.

## Setup and reproduction

Use Python 3.10 or later. From the repository root:

```sh
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
make all
```

This repository currently contains the project scaffold. All `.py` files are
empty placeholders. `make all` exits with an explicit message until the pipeline
is implemented; no results are generated yet. The initial sample periods,
universe, parameters, and random seed are recorded in `configs/config.yaml`.

The planned script order is:

1. `scripts/01_get_data.py` — acquire source data.
2. `scripts/02_build_dataset.py` — clean and merge the analysis dataset.
3. `scripts/03_replicate.py` — reproduce the original-paper experiment.
4. `scripts/04_extend.py` — run the extension experiments.

All research logic belongs in the importable `src/project/` package. Notebooks
are for exploration; reported results must be generated by the pipeline.
The `tests/` directory is reserved for meaningful sanity checks as the research
code is implemented; no research tests or results are included yet.

## Data and results map

| Location | Contents |
| --- | --- |
| `data/raw/` | Untouched source downloads |
| `data/interim/` | Cleaned and merged intermediate datasets |
| `data/processed/` | Final analysis-ready datasets |
| `results/replication/tables/` | Original-paper replication tables |
| `results/replication/figures/` | Original-paper replication figures |
| `results/extension/tables/` | Extension comparison tables |
| `results/extension/figures/` | Extension comparison figures |
| `report/` | Write-up and slides |

Sixteen public French factor/portfolio archives are tracked with Git LFS. After
cloning, install Git LFS and run `git lfs pull` to retrieve the actual ZIP files.
See [data/README.md](data/README.md) for the download inventory, source attribution,
checksums, and instructions for reacquiring local-only inputs.

The blanket `data/` ignore from the course template is omitted. Licensed CRSP and
TAQ observations and Goyal–Welch source workbooks remain local in ignored raw
directories. Their acquisition records and source notes are included.
See the [WRDS data policy](https://wrds-www.wharton.upenn.edu/pages/about/data-download-and-analysis-policy/).
Generated results are ignored, apart from directory placeholders, and should be
rebuildable once the pipeline is implemented. Never commit credentials.
