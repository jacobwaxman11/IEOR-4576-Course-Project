## Setup and reproduction

Use Python 3.10 or later. From the repository root:

```sh
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
make all
```

Re-run `pip install -e ".[dev]"` after pulling a change to `pyproject.toml`: Table 4's Ibbotson
block reads the Goyal-Welch `.xls` through `xlrd`, and without it the check prints a warning and
leaves those 24 cells unscored. `git lfs pull` fetches the factor files under `data/raw/french`
and `data/raw/goyal_welch`; without them the factor-regression rows are not computed either.

The pipeline is implemented, in two targets. `make benchmark` reproduces the check (411.0 of 865)
from the shared cohort caches and the four side caches and scores it into `eval/score.json`; it
reads the caches under `REPL` with the interpreter in `PYTHON`, so a checkout whose caches live
elsewhere runs `make benchmark PYTHON=$PWD/.venv/bin/python REPL=/path/to/data/processed/replication`.
`make outputs` regenerates the committed tables and figures and the pages' generated blocks from the
check, but does not rerun the check. The initial sample periods, universe, parameters, and random
seed are recorded in `configs/config.yaml`; the result is summarized under "Replication status"
below.

### WRDS access

Data are pulled with the official `wrds` Python package. Each teammate stores
their own credentials once, outside the repository:

```sh
.venv/bin/python scripts/wrds_setup.py   # run in your own terminal; approve the Duo push
```

The script prompts for the password without echoing it and writes it to
`~/.pgpass` (mode 600). Code connects with `project.data.wrds_connection()`,
which reads that file and never takes a password argument. Each new connection
can trigger a Duo push, so reuse one connection per session. API pulls land in
the git-ignored `data/raw/wrds_api/`. Run `pre-commit install` once to block
commits that contain secrets.

The script order is:

1. `scripts/01_get_data.py` — acquire source data.
2. `scripts/02_build_dataset.py` — clean and merge the analysis dataset.
3. `scripts/03_replicate.py` — reproduce the original-paper experiment.
4. `scripts/04_extend.py` — run the extension experiments.

All research logic belongs in the importable `src/project/` package. Notebooks
are for exploration; reported results must be generated by the pipeline.
The `tests/` directory holds the suite that pins the check, the mark rule, the
865-cell ceiling and the ledgers' arithmetic.

## Replication status

**Thesis.** Gatev, Goetzmann and Rouwenhorst (2006) find that a simple pairs-trading rule earns
large, significant excess returns that transaction costs, conventional risk factors and
short-term reversal do not explain. They link the profits to a latent common factor that weakened
after 1988. Rebuilt from CRSP with the paper's stated rules, **the paper's conclusions replicate
but its tables only partly do**. Of its 24 testable claims, 20 replicate (5 with the paper's
numbers, 15 in direction and significance), 3 partly, and 1 does not hold as stated (the top-20
long-book alpha is significant); the four that fall short are measured under every reading the
paper leaves open. The abstract's
"temporary mispricing" is the paper's interpretation and is not counted. The check scores 411.0
weighted points over the 865 distinct numbers the paper prints about its results (✓ within 10% = 1,
~ within 25% = ½): 322 cells within 10% and 500 within 25%. No reading the paper's text supports
beats 411.0, and every reading that scores higher is measured and not adopted ("Status" above). The
location, dispersion and composition of every series replicate (81% of those cells); the misses fall
into nine named classes (`GAPS.md` section 2). The gaps trace to data and to underspecified methods,
above all a reversal factor the paper's description does not pin down.

- **Start here:** [`report/replication/README.md`](report/replication/README.md),
  which has the thesis, every table and figure against the paper (marks generated from the
  check), and the map of the replication folder's pages.
- **Generated tables and Figures 1-4:** [`report/replication/outputs/`](report/replication/outputs/),
  regenerated by `make outputs`; cell by cell:
  [`REPLICATION_CHECK.md`](report/replication/REPLICATION_CHECK.md).
- **Score history and counting rule:** [`report/replication/SCORE_LOG.md`](report/replication/SCORE_LOG.md).

- **Systematic risk (Tables 4 and 8).** With French's short-term reversal factor (ST_Rev), the
  paper's conclusion replicates: pairs returns load little on the Fama-French, momentum and
  reversal factors, and keep a significant Newey-West alpha before 1989 and after 1988, smaller
  in the second period. Cell-level agreement is poor, because the paper's own reversal factor
  is unidentified before 1989 and most post-1988 coefficients are statistically zero, with our
  post-1988 all-pairs portfolio off by an era split in the stock universe. Details:
  [`GAPS.md`](report/replication/GAPS.md) (the census and the paper's own arithmetic).
- **Every claim, with evidence.** [`CLAIMS.md`](report/replication/CLAIMS.md) lists each
  substantive claim of the abstract, sections 3.1-3.9 and the conclusion, with a
  claims-to-cells map and a verdict that cites the check rows it rests on, including the
  Table 7 long/short result.
- **What the paper's own numbers imply.** What the printed statistics imply about the unnamed
  reversal factor is set out in [`GAPS.md`](report/replication/GAPS.md) (section 11), with the
  machine records in [`analysis/`](report/replication/analysis/).
- **Open gaps** are tracked in [`GAPS.md`](report/replication/GAPS.md) (Q1-Q12), with the dated
  experiment rounds in [`archive/`](report/replication/archive/).
